# Bex Personal Training — V2

This is the second design pass for Bex Haywood's personal training website.

## What changed

- Stronger brand direction around Bex's real coaching philosophy
- Rewritten bio using Bex's original wording and tone
- Three-principle "My Approach" section
- More premium editorial layout
- Mobile navigation
- Subtle scroll-reveal animation
- Updated phone and email details
- Dedicated profile image section

## Images required

Add these two files to `/images`:

- `hero.jpg` — ideally a strong wide photograph of Bex training, with room on the left for text
- `bex-profile.jpg` — ideally a portrait or training image of Bex, vertical orientation

The site still works without them, but those image filenames are expected by the CSS/HTML.

## Local preview

Open `index.html` with VS Code Live Server.

## Publish

Copy these files into your existing repo, then:

```bash
git add .
git commit -m "Redesign Bex website"
git push
```

Cloudflare should deploy automatically from GitHub.
